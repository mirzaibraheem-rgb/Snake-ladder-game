SOFT Snakes and Ladders is an educational game for children aged 8 to 16 that teaches safe online habits.

## The short version

**We do not collect, store, or share any information about you or your child.** The game works completely offline.

## What the game does not do

- It does not collect names, ages, locations, contacts, photos, device identifiers, or any other personal information.
- It does not use analytics, tracking, or crash reporting tools.
- It does not show advertisements.
- It does not offer in app purchases.
- It does not require an account or a login.
- It does not contain links to websites, social media, or other apps.
- It does not include any third party code that collects data.
- It does not use the camera, microphone, contacts, or location.

## Information that stays on the device

The game remembers a few things **only on the device**, so it can work properly:

- The player names typed on the setup screen, and the characters chosen, for the current game.
- Game settings (language, sound, music, rules).
- An unfinished game, so it can be continued after an accidental close.

This information never leaves the device. It is never sent to us or to anyone else. Deleting the app (or clearing the browser's site data, for the web version) removes it completely.

## Children's privacy

The game is designed for children. Because no personal information is collected, the game complies with the Children's Online Privacy Protection Act (COPPA), the EU General Data Protection Regulation (GDPR), Google Play Families Policy, and the Apple App Store Kids Category guidelines with respect to data collection.

## Internet permission (Android)

The Android version lists the standard "internet" permission because the app's built in web viewer requires it. The game never uses the internet: every file it needs is inside the app.

If this policy ever changes, the new version will be published with an updated effective date before the change takes effect.
